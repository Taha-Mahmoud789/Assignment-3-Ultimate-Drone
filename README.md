# DJI Mavic 4 Pro — Product Page

> A fully responsive product page for the DJI Mavic 4 Pro drone, built with pure HTML & CSS.

---

## 📄 Project Description

A modern, responsive product page that showcases the DJI Mavic 4 Pro drone. The page includes a hero section, comparison table, customer reviews with a sticky sidebar, related products, and a full footer.

---

## 🛠️ Technologies Used

| Technology | Usage |
|------------|-------|
| **HTML5** | Page structure & semantic elements |
| **CSS3** | Styling, animations, Flexbox, Float layout |
| **Sticky Positioning** | Reviews summary sidebar |
| **CSS Transitions** | Hover effects & underline animations |
| **Responsive Units** | `vh`, `%`, `px` for layout sizing |
